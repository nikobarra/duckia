## Notas técnicas relevantes

- `logo_nuevo.jpeg` NO es apto para uso directo: tiene un tablero de ajedrez gris horneado como píxeles opacos (no transparencia real). Usar `logo_fondo_negro.jpeg` como fuente para cualquier recorte futuro del logo.
- Zernio (y la API de Instagram en general) NO permite editar foto de perfil, bio ni destacadas por API — es una limitación de la plataforma (Meta), no de Zernio. Esos cambios se hacen a mano en la app. Zernio sí puede publicar posts/historias/reels vía API, pero el texto no se renderiza en historias publicadas por API (hay que hornearlo en la imagen) y agrupar historias en destacadas tampoco tiene endpoint público.
- Assets generados en esta sesión (en `D:\proyectos\Duckia_Impecable\`): `duckia_foto_perfil_ig.jpg` (foto de perfil recortada), `destacada_que_es_duckia.png`, `destacada_servicios.png`, `destacada_contacto.png` (portadas de destacadas, generadas con kie.ai nano-banana-2-lite, costo real ~US$0.06).
